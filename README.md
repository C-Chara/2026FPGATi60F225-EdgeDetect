# 逐光寻边：基于 Ti60 FPGA 的实时图像边缘检测与识别系统

2026 全国大学生嵌入式芯片与系统设计竞赛 FPGA 赛道 · 易灵思赛题四 · 三三队

OV5640 摄像头 → Ti60F225 FPGA 全硬件流水线处理 → 1280×720@60Hz HDMI 输出。灰度化、中值滤波、Canny 边缘检测、自适应阈值、几何图形识别、数字识别、DDR 帧冻结与回放全部在 FPGA 逻辑中完成，不使用处理器。

## 功能一览

| 赛题要求 | 实现情况 |
|---|---|
| 摄像头采集 ≥ 640×480，无丢帧 | 1280×720，60 fps（屏幕左上角 FPS 实时测量） |
| 灰度化（DSP 或移位加法） | (77R + 150G + 29B) / 256，全部移位加法，不占乘法器 |
| 3×3 Sobel，G = \|Gx\| + \|Gy\|，阈值可配置，2 行行缓存 | ✓ |
| HDMI 显示，分屏或画中画 | 720p60；分屏（左原图、右边缘）、彩色叠加等 5 种显示模式 |
| 高阶 1：3×3 中值滤波，并行排序网络 | 三级选择网络，19 次比较，可开关，并可注入椒盐噪声做对比 |
| 高阶 2：按键调阈值，按键消抖 | K1/K2 每次 ±8；另有上电默认开启的自适应阈值 |
| 高阶 3：DDR 帧缓存，冻结、回放、多帧对比 | DDR3 环形缓存最近 4.2 秒（254 帧）：冻结、逐帧前后翻、1/4 速慢动作回放；帧差模式标出相邻两帧间变化的像素 |
| 高阶 4：Canny | 高斯平滑 → Sobel 梯度与方向 → 非极大值抑制 → 双阈值滞后连接 |
| 高阶 5：彩色边缘叠加 | 红色边缘叠加在原始彩色画面上 |
| 高阶 6：简易目标识别 | 连通域标记 + 矩特征，识别圆、椭圆、正方形、长方形、三角形；7×9 模板匹配识别数字 1–9 |

另外还做了：
- **时域稳定：** DDR 时域降噪，加上边缘跨帧保持，静止画面边缘不闪烁，移开物体后不留残影。
- **局部阈值：** 识别用的二值化按局部亮度调整，光照不均、纸张不在画面中央时也能识别。
- **跨帧投票：** 识别结果连续多帧一致才显示和切换，标签不跳。
- **颜色归属：** 每个图形的边缘按等效椭圆归给最近的图形，旋转时相邻图形不会互相串色。

## 按键操作

| 操作 | 作用 |
|---|---|
| K1 / K2 短按 | 阈值 +8 / −8（第一次按下从自动切到手动） |
| K1+K2 同时短按 | 自动阈值下：中值滤波演示循环 MED ON → MED OFF → MED OFF + 噪声 → MED ON + 噪声；手动阈值下：回到自动 |
| K1 长按 | 显示模式：彩色叠加 → 分屏 → 帧差 → 灰度叠加 → 黑底边缘 |
| K2 长按 | 冻结画面，进入回放；再长按回到实时 |
| K1+K2 同时长按 | 图形与数字识别 开 / 关 |
| 冻结时 K2 / K1 短按 | 往前 / 往后一帧 |
| 冻结时 K1+K2 短按 | 慢动作回放 开 / 关 |

屏幕左上角显示：FPS（帧率）、THR（阈值，A 表示自动）、MED（中值滤波）、REC（识别）；冻结时显示 FRZ / PLY -帧数；注入噪声时显示 NOISE。

## 处理流水线

```
OV5640 (RAW8, 60 fps)
  → 去马赛克 → DDR3 帧缓存（时域降噪 + 运动标记，256 帧环形缓存）
  → 灰度化 → 3×3 中值滤波 → 3×3 高斯 → Sobel → 非极大值抑制 → 双阈值滞后连接
  → 碎片过滤 → 时域稳定 → 显示模式选择 / 叠加
  → 图形识别（640×360 连通域 + 矩特征）、数字识别（7×9 模板）、OSD
  → HDMI 1280×720@60Hz
```

每一级都是逐像素流水，模块之间用寄存器打拍，没有反馈环，每个时钟出一个像素。3×3 窗口由两条行缓存加移位寄存器构成。

## 验证

- **图形识别：** 硬件模块 `shape_detector.v` 与 Python 参考模型 `tools/models/shape_ccl_model.py` 在 12 个测试场景下结果逐个一致。场景包括光照渐晕、印刷污渍、条纹、小目标、纹理背景、杂乱背景、棋盘格、重叠等。
- **数字识别和其他模块：** 数字识别、跨帧投票、按键、着色都有独立的测试平台，位于 `sim/` 目录。
